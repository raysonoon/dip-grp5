## Deployment

### Frontend
- Cloudflare pages

### Backend
- Google Cloud Run
  - Deploy docker container
  - Free tier
    - CPU - First 240,000 vCPU-seconds free per month i.e. vCPU usage over time
    - RAM - First 450,000 GiB-seconds free per month i.e. RAM usage over time
    > 1 GiB is similar to gigabyte
  - `asia-southeast1` more expensive tier 2 pricing

### DB
